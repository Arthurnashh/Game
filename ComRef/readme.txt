Browser independent ComRef documentation
========================================

Follow the steps:
1. Get the whole directory from the source safe.
2. Get the data\comref.xml into this directory (from this one the whole documentation is generated!)
3. run the generateComRef.bat
... and enjoy the comref ;)

Note: 
 * comref is generated into html subdirectory
 * so the html/comref.html is the starting point to use
